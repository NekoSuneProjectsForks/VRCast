VRCast（BOOTH）
===============

[日本語]

この zip にはアプリ本体は入っていません。
セットアップ時に GitHub から最新版をダウンロードします（インターネット接続が必要です）。

■ 使いかた（おすすめ）
1. VRCast-*-win64-setup.exe を起動する
2. 展開先のフォルダーを選んで「展開する」を押す
3. 終わったら VRCast フォルダーの VRCast.exe で起動する
   アバターの書き出しツールは VRCast-Converter フォルダーにあります

■ バッチで zip だけ欲しいとき
- Download-VRCast.bat をダブルクリックすると、同じフォルダーに最新の
  VRCast-*-win64.zip をダウンロードします（展開はエクスプローラーで行ってください）

■ 更新について
アプリを一度入れたあとは、アプリ内の自動更新でも新しい版にできます。
この BOOTH の zip を毎回置き直す必要はありません。


[English]

This zip does not include the full app.
The latest build is downloaded from GitHub when you set up (internet required).

- Recommended
1. Run VRCast-*-win64-setup.exe
2. Choose a folder and click Extract
3. Start with VRCast\VRCast.exe
   The avatar exporter is in the VRCast-Converter folder

- Download the zip only
- Double-click Download-VRCast.bat to save the latest VRCast-*-win64.zip
  next to the batch file (extract it yourself in Explorer)

- Updates
After the first install, the app can update itself.
You do not need a new BOOTH zip every release.


[한국어]

이 zip에는 앱 본체가 들어 있지 않습니다.
설치 시 GitHub에서 최신판을 다운로드합니다(인터넷 연결 필요).

■ 사용 방법(권장)
1. VRCast-*-win64-setup.exe를 실행합니다
2. 압축을 풀 폴더를 선택한 뒤 「압축 해제」를 누릅니다
3. 끝나면 VRCast 폴더의 VRCast.exe로 시작합니다
   아바타 내보내기 도구는 VRCast-Converter 폴더에 있습니다

■ zip만 필요할 때
- Download-VRCast.bat를 더블 클릭하면 같은 폴더에 최신
  VRCast-*-win64.zip을 저장합니다(압축 해제는 탐색기에서 하세요)

■ 업데이트
앱을 한 번 설치한 뒤에는 앱 안의 자동 업데이트로도 새 버전을 받을 수 있습니다.
BOOTH zip을 매번 다시 받을 필요는 없습니다.


[简体中文]

此 zip 不包含完整应用程序。
设置时会从 GitHub 下载最新版（需要互联网连接）。

■ 推荐用法
1. 运行 VRCast-*-win64-setup.exe
2. 选择解压文件夹并点击「解压」
3. 完成后通过 VRCast 文件夹中的 VRCast.exe 启动
   虚拟形象导出工具在 VRCast-Converter 文件夹中

■ 只需 zip 时
- 双击 Download-VRCast.bat，即可在同级文件夹保存最新的
  VRCast-*-win64.zip（请自行用资源管理器解压）

■ 关于更新
首次安装后，也可以通过应用内的自动更新获取新版本。
不必每次都重新下载 BOOTH 的 zip。


[繁體中文]

此 zip 不包含完整應用程式。
設定時會從 GitHub 下載最新版（需要網際網路連線）。

■ 建議用法
1. 執行 VRCast-*-win64-setup.exe
2. 選擇解壓資料夾並按「解壓」
3. 完成後透過 VRCast 資料夾中的 VRCast.exe 啟動
   虛擬形象匯出工具在 VRCast-Converter 資料夾中

■ 只需 zip 時
- 連按兩下 Download-VRCast.bat，即可在同一資料夾儲存最新的
  VRCast-*-win64.zip（請自行用檔案總管解壓）

■ 關於更新
首次安裝後，也可以透過應用程式內的自動更新取得新版本。
不必每次都重新下載 BOOTH 的 zip。
